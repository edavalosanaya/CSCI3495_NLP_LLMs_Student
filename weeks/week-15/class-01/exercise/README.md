# W15C1 Lab: Measuring Bias, Not Just Asserting It

Everything for this session is in **`lab.ipynb`**. We work through it together in
class, cell by cell. The 3 `YOUR TURN` cells are the parts you edit.

## Getting started

Once, from the repository root on your own machine:

```
uv sync
```

Then open `weeks/week-15/class-01/exercise/lab.ipynb` in your editor, select the project's
**`.venv`** kernel, and run the cells from the top with Shift + Enter. There is
nothing else to install.

## What you will do

1. Measure an association in a real pretrained model, with a number.
2. Check whether that number could have happened by chance.
3. Try to remove the bias, and see how much you actually removed.

## What is in this folder

| File | What it is |
|---|---|
| `lab.ipynb` | The session: notes, working code, 3 `YOUR TURN` tasks, and the answers. |

## How this lab works

Everything already runs the moment you open it. Nothing raises, and there is no
test to run and nothing to submit. Every `YOUR TURN` cell says in a comment what
you should see when it is right, in real numbers, and the answers are in the
last cell of the notebook.

Read the output and judge whether it looks right. That is the skill.
