# W3C1: Loading, shaping and seeing a dataset

Everything for this session is in **`lab.ipynb`**. We work through it together in
class, cell by cell. It opens with **Part 0**, a short Python refresher: variables,
lists, dictionaries, loops and functions. Every part ends with a `TRY IT`: a question, an empty cell,
and at most three lines of your own code. The two `YOUR TURN` cells at the end
are the post-break work.

## Getting started

Once, from the repository root on your own machine:

```
uv sync
```

Then open `weeks/week-03/class-01/exercise/lab.ipynb` in your editor, select the
project's **`.venv`** kernel, and run the cells from the top with Shift + Enter.
There is nothing else to install.

## What is in this folder

| File | What it is |
|---|---|
| `lab.ipynb` | The session. Notes, working code, six `TRY IT` checkpoints, two `YOUR TURN` tasks, and the answers. |
| `data/reviews.csv` | 240 movie reviews with a label, a star rating, a genre and a year. |

## How this lab works

Everything already runs the moment you open it. Nothing raises, and there is no
test to run and nothing to submit. Every `TRY IT` and `YOUR TURN` says in a
comment what you should see when it is right, in real numbers, and the answers
are in the last cell of the notebook.

Read the output and judge whether it looks right. That is the skill.
